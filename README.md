# Sistema de Gestión y Seguimiento de Servicio Médico (SGSM) - EHS Hunter

Este proyecto es una plataforma web completa diseñada para la gestión clínica, nutricional y de seguridad e higiene (EHS). Permite realizar evaluaciones médicas, físicas y de seguimiento para diversos programas de salud corporativa.

## Características Principales
- **Flujo Unificado**: 8 pasos detallados para evaluaciones integrales.
- **Seguridad y Acceso**: Sistema de autenticación con roles protegidos.
- **Diseño Premium**: Interfaz moderna con efectos de glassmorphism y fondos dinámicos.
- **Persistencia**: Manejo de borradores locales y sincronización con Google Sheets (vía Google Apps Script).
- **Despliegue**: Hosting optimizado en Firebase.

## Tecnologías
- HTML5 / CSS3 / JavaScript (Vanilla)
- Firebase Hosting
- Google Apps Script (Backend/Sheets)
- Inter Font & Heroicons
